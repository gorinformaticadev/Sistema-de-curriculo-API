================================================================================
ESTRUTURA DO BANCO DE DADOS
================================================================================

NOVA TABELA: form_interactions

Campos:
- id                    INT AUTO_INCREMENT PRIMARY KEY
- session_id            VARCHAR(255) NOT NULL
- ip                    VARCHAR(45) NOT NULL
- user_agent            TEXT
- browser               VARCHAR(100)
- os                    VARCHAR(100)
- device                VARCHAR(50)
- nome_completo         VARCHAR(255) DEFAULT NULL
- ultimo_campo          VARCHAR(100)
- acao                  VARCHAR(50)
- valor_campo           TEXT
- timestamp             TIMESTAMP DEFAULT CURRENT_TIMESTAMP

Índices:
- idx_session           (session_id)
- idx_ip                (ip)
- idx_timestamp         (timestamp)

================================================================================
NOVAS APIs REST (admin.php)
================================================================================

1. getInteractionStats
   └── Retorna: Total de sessões, completos, abandonos, taxa de conversão

2. getAbandonmentAnalysis
   └── Retorna: Top 10 campos com maior abandono

3. getInteractionSessions
   └── Retorna: Lista de sessões com filtros (período, dispositivo, nome)

4. getSessionDetails
   └── Retorna: Timeline completa de uma sessão específica
