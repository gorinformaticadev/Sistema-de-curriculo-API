Aceitar HTTP 201 (Created) da API Pluggor como sucesso de envio

- Fenomeno: foto e PDF do curriculo pareciam nao enviados - os logs
  mostravam 'Falha ao enviar' para todas as chamadas
- Causa raiz: a API Pluggor responde HTTP 201 (Created) com
  {"success":true,"messageId":"..."} em envios bem-sucedidos,
  mas o sistema tratava como sucesso apenas HTTP 200, marcando
  texto, foto e PDF como falha (embora enviados de verdade)
- Correcao: todas as validacoes de envio agora aceitam a faixa
  2xx (200-299): sendApiTextMessage, sendApiMediaMessage,
  teste de API do painel, envio de WhatsApp do modal e teste da
  API na tela de configuracoes
- Validado com token real: foto, texto e PDF aceitos pela API
  (messageId retornado) sem entradas de falha no log
- Pacote de atualizacao v3.2.6 gerado
