Informações de Contato

Nova funcionalidade para gerenciar contatos dos candidatos

Importante: Esta funcionalidade adiciona uma nova tabela ao banco de dados. Execute o script de instalação antes de usar.

Instalação Rápida

1

Execute o Script de Atualização

Acesse o arquivo de atualização no seu navegador:

http://seu-dominio.com/update_add_contact_info.php

Este script criará a tabela curriculo_contatos no banco de dados.

Executar Agora
2

Verifique a Instalação

Após executar o script, você verá uma mensagem de confirmação indicando que a tabela foi criada com sucesso.

3

Acesse o Painel Administrativo

Faça login no painel administrativo e vá para a aba "Currículos".

Ir para o Painel
4

Use a Nova Funcionalidade

Na listagem de currículos, você verá um novo ícone azul de caderneta na coluna "Contato". Clique nele para gerenciar as informações de contato do candidato.

Pronto! A funcionalidade está instalada e pronta para uso.

Atualize os dados sempre que necessário

Telefone, Email, WhatsApp, LinkedIn e mais

Seguro

Proteção CSRF e logs de auditoria

Atenção: Certifique-se de fazer backup do banco de dados antes de executar qualquer script de atualização.

Como Usar

  1. Acesse o painel administrativo
  2. Vá para a aba "Currículos"
  3. Clique no ícone azul de caderneta () na coluna "Contato"
  4. No modal que abrir, clique em "Adicionar Informação"
  5. Selecione o tipo de contato (Telefone, Email, etc.)
  6. Digite a informação e observações (opcional)
  7. Clique em "Salvar"
