Checklist de Atualização

Sistema de Logs Refinado v2.0

0%

⚠️ Importante: Faça Backup Primeiro!

Antes de prosseguir, certifique-se de ter um backup completo do banco de dados. Embora o modo de atualização preserve os dados, é sempre melhor prevenir.

1. Preparação ⏱️ 5 min
Fazer backup do banco de dados
Execute o comando abaixo para criar um backup completo:
mysqldump -u usuario -p nome_banco > backup_$(date +%Y%m%d).sql
Fazer backup dos arquivos atuais
Copie todos os arquivos do sistema para uma pasta de backup.
Baixar os novos arquivos
Certifique-se de ter todos os arquivos da versão 2.0 prontos para upload.
2. Upload dos Arquivos ⏱️ 3 min
Fazer upload dos novos arquivos
Envie todos os arquivos novos e modificados para o servidor via FTP/SFTP.
Novos: form-tracker.js, log_interaction.php, update_database.php, test_system.php
Modificados: index.html, admin.php, install.php
Verificar permissões de arquivos
Certifique-se de que os arquivos PHP têm permissão de execução (644) e o diretório uploads tem permissão de escrita (755).
3. Executar Instalador ⏱️ 2 min
Acessar o instalador
Abra no navegador: http://seu-dominio.com/install.php
Selecionar modo "Atualizar Sistema"
No campo "Modo de Instalação", selecione: "Atualizar Sistema (Manter dados existentes)"
Preencher credenciais do banco
Informe: Nome do banco de dados, Usuário e Senha (mesmos do sistema atual)
Executar instalação
Clique em "Instalar" e aguarde a mensagem de sucesso. A tabela form_interactions será criada automaticamente.
Deletar install.php
IMPORTANTE: Por segurança, delete ou renomeie o arquivo install.php após a instalação.
4. Testes e Verificação ⏱️ 5 min
Executar test_system.php
Acesse: http://seu-dominio.com/test_system.php
Verifique se todos os testes passaram com ✅
Verificar tabela form_interactions
Confirme que a nova tabela foi criada no banco de dados.
Acessar painel administrativo
Faça login em: http://seu-dominio.com/admin.php
Verificar nova aba "Interações do Formulário"
Confirme que a nova aba está visível e carrega corretamente.
Testar formulário público
Acesse o formulário e interaja com alguns campos. Depois, verifique se as interações aparecem no dashboard.
Verificar estatísticas no dashboard
Confirme que os 4 cards de estatísticas estão exibindo dados (pode levar alguns minutos para acumular dados).
5. Finalização ⏱️ 2 min
Limpar cache do navegador
Pressione Ctrl+F5 (ou Cmd+Shift+R no Mac) para garantir que está vendo a versão mais recente.
Deletar test_system.php
Por segurança, delete o arquivo de teste após confirmar que tudo está funcionando.
Documentar a atualização
Registre a data da atualização e a versão instalada (v2.0) para referência futura.
Ler documentação
Familiarize-se com os novos recursos lendo INSTALACAO.md e ATUALIZACAO_v2.0.md

Parabéns!

Você completou todos os passos da atualização!

O sistema v2.0 está pronto para uso. Agora você pode monitorar todas as interações do formulário e otimizar a taxa de conversão com base em dados reais.
