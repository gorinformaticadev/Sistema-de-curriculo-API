Sistema de Rastreamento de Interações do Formulário

100% Completo

Fase 1: Estrutura do Banco de Dados

Criação da infraestrutura de armazenamento

Tarefa 1.1: Criar tabela form_interactions

Nova tabela para armazenar todas as interações do formulário

  • Campos: session_id, ip, user_agent, browser, os, device
  • Campos: nome_completo, ultimo_campo, acao, valor_campo, timestamp
  • Índices otimizados para consultas rápidas

Fase 2: Sistema de Tracking Frontend

Captura inteligente de interações do usuário

Tarefa 2.1: Criar form-tracker.js

Sistema JavaScript para rastreamento em tempo real

  • Detecta foco, mudanças e seleções em todos os campos
  • Captura nome completo quando preenchido
  • Envia dados via AJAX a cada 5 segundos
  • Garante envio antes de sair da página (beforeunload)

Tarefa 2.2: Criar log_interaction.php

Endpoint PHP para processar e salvar interações

  • Detecta automaticamente navegador, SO e dispositivo
  • Valida e sanitiza dados recebidos
  • Salva no banco de dados com timestamps precisos

Fase 3: Visualização Moderna

Interface visual e intuitiva para análise de dados

Tarefa 3.1: Nova aba "Interações do Formulário"

Dashboard completo com visualizações modernas

  • 4 cards de estatísticas principais
  • Gráfico de barras para análise de abandono
  • Filtros por período, dispositivo e nome
  • Lista de sessões com status visual
  • Timeline expandível de cada sessão

Tarefa 3.2: APIs REST para dados

4 novos endpoints no admin.php

  • getInteractionStats - Estatísticas gerais
  • getAbandonmentAnalysis - Análise de abandono por campo
  • getInteractionSessions - Lista de sessões com filtros
  • getSessionDetails - Timeline detalhada de uma sessão

Fase 4: Instalador com Modo Atualização

Sistema inteligente de instalação e atualização

Tarefa 4.1: Modificar install.php

Suporte para instalação nova e atualização

  • Seleção de modo: Instalar vs Atualizar
  • Detecta banco de dados existente
  • Cria novas tabelas sem perder dados
  • Validações específicas por modo
