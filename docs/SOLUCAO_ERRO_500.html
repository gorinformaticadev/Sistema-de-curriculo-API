Solução para Erro 500

Problema com arquivo .htaccess

Erro 500 - Erro Interno do Servidor
Este erro geralmente é causado por um problema no arquivo .htaccess

O que causa o erro?

O erro 500 pode ser causado por:

  • Diretivas não suportadas pelo seu servidor Apache
  • Módulos do Apache não habilitados (mod_rewrite, mod_headers, etc.)
  • Sintaxe incorreta no .htaccess
  • Configurações PHP não permitidas
  • Permissões incorretas de arquivo

Soluções

Solução 1: Usar versão simplificada do .htaccess

Já criei uma versão simplificada que deve funcionar na maioria dos servidores.

Passos:

  1. Renomeie o arquivo atual: .htaccess → .htaccess.backup
  2. Renomeie o arquivo: .htaccess.simple → .htaccess
  3. Teste o site novamente

Solução 2: Remover temporariamente o .htaccess

Para verificar se o problema é realmente o .htaccess:

  1. Renomeie .htaccess para .htaccess.disabled
  2. Teste o site
  3. Se funcionar, o problema está no .htaccess
  4. Use a versão simplificada ou adicione as regras uma por vez

Solução 3: Verificar logs de erro do Apache

Os logs mostram exatamente qual linha está causando o problema.

Locais comuns dos logs:

  • cPanel: Painel → Logs → Error Log
  • XAMPP: xampp/apache/logs/error.log
  • Linux: /var/log/apache2/error.log

Solução 4: Verificar módulos do Apache

Alguns módulos podem não estar habilitados no seu servidor.

Módulos necessários:

  • mod_rewrite - Para regras de reescrita
  • mod_headers - Para headers de segurança
  • mod_deflate - Para compressão GZIP
  • mod_expires - Para cache

Como habilitar (se tiver acesso SSH):

sudo a2enmod rewrite sudo a2enmod headers sudo systemctl restart apache2

Solução 5: Remover configurações PHP

Algumas hospedagens não permitem alterar configurações PHP via .htaccess.

Remova estas linhas se causarem erro:

php_value upload_max_filesize 10M php_value post_max_size 10M php_flag engine off

Use php.ini ou .user.ini ao invés disso.

Versão Mínima do .htaccess

Use esta versão se todas as outras falharem:
# Versão MÍNIMA - Apenas proteções essenciais Options -Indexes # Bloquear logs <Files "error.log"> Order Allow,Deny Deny from all </Files> <Files "access.log"> Order Allow,Deny Deny from all </Files>

Checklist de Verificação

Antes de aplicar qualquer solução:
  1. ☐ Faça backup do .htaccess atual
  2. ☐ Verifique os logs de erro do Apache
  3. ☐ Teste com a versão simplificada primeiro
  4. ☐ Adicione regras uma por vez se necessário
  5. ☐ Verifique permissões (644 para .htaccess)

Comandos Úteis (SSH)

# Ver últimas linhas do log de erro tail -n 50 /var/log/apache2/error.log # Verificar sintaxe do Apache apachectl configtest # Verificar módulos habilitados apache2ctl -M # Corrigir permissões chmod 644 .htaccess

Suporte da Hospedagem

Se nada funcionar:
Entre em contato com o suporte da sua hospedagem e informe:
  • Erro 500 ao acessar o site
  • Problema relacionado ao arquivo .htaccess
  • Peça para verificar os logs de erro do Apache
  • Pergunte quais módulos estão habilitados
  • Pergunte se há restrições para .htaccess

Dicas Importantes

  • Sempre faça backup antes de modificar o .htaccess
  • Teste em ambiente de desenvolvimento primeiro
  • Adicione regras gradualmente para identificar problemas
  • Verifique a documentação da sua hospedagem
  • Use a versão simplificada se tiver dúvidas
Versão Simplificada Aplicada!
