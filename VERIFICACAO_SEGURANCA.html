Proteção do Diretório de Uploads

Execução de PHP Desabilitada

O diretório /uploads/ tem php_flag engine off

Proteção: Mesmo que alguém faça upload de um arquivo PHP malicioso, ele não será executado.

Apenas Imagens e PDFs Permitidos

Somente arquivos .jpg, .jpeg, .png, .gif e .pdf são permitidos.

Bloqueados: .php, .exe, .sh, .py, .pl, .asp, .jsp, .cgi

Headers de Segurança HTTP

Headers Implementados

Os seguintes headers de segurança estão configurados:

  • X-Frame-Options: SAMEORIGIN - Previne clickjacking
  • X-Content-Type-Options: nosniff - Previne MIME sniffing
  • X-XSS-Protection: 1; mode=block - Proteção XSS
  • Referrer-Policy - Controla informações de referência
  • Content-Security-Policy - Controla recursos carregados

Teste: Use ferramentas online para verificar os headers.

Proteção contra Ataques

SQL Injection

Proteção em .htaccess: Bloqueia query strings com palavras-chave SQL suspeitas

Proteção em código: Uso de prepared statements em todas as queries

XSS (Cross-Site Scripting)

Proteção: Sanitização de saída com htmlspecialchars()

Bloqueio: Query strings com tags <script> são bloqueadas

CSRF (Cross-Site Request Forgery)

Proteção: Tokens CSRF em todas as operações POST

Todas as ações administrativas verificam o token antes de executar.

Bots e Scanners

Bloqueados: User agents suspeitos como curl, wget, nikto, HTTrack

Requisições com user agents vazios ou de ferramentas de scan são bloqueadas.

  • ☐ Alterar credenciais do banco de dados
